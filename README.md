# MATLAB Physics-Informed Neural Networks (PINNs)

This repository contains several MATLAB implementations of physics-informed neural networks (PINNs) applied to simple physical systems, including mass–spring–damper, drag motion, and other toy models.

Each script demonstrates a different loss formulation or training approach, combining experimental / simulated data with the underlying differential equation via automatic differentiation.

## Techniques
- PINN architectures
- Automatic differentiation
- ODE residual loss
- Data + physics training
- MATLAB Deep Learning Toolbox

## Topics
- Scientific Machine Learning
- Deep Learning
- Numerical modeling
- Signal processing
